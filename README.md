## Part 1. Media Queries
I used media queries at 576px and 993px to change the font sizes and box widths. For the layout, I used Flexbox with wrapping and widths of 100%, 49%, and 32%. This allows the three boxes to fit on different screens without using Bootstrap grid classes.

## Part 2. Bootstrap Grid System
I added Bootstrap through a CDN and used col-12 col-md-6 col-lg-4 for the three columns. These classes control how much space each column takes at different screen sizes. I also added a navbar with my NKDR logo and links to the page sections. I used ms-auto to move the links to the right and Bootstrap’s JavaScript bundle to make the hamburger menu open and close.

## Part 3. Combined Project
I added a portfolio section to the same page, using 8 grid columns for my projects and 4 for my personal information on desktop. On smaller screens, the personal information moves below the projects. The project buttons link to my earlier sections. I also added a footer and custom media queries to adjust font sizes and padding. On mobile, I hide the extra introduction sentence with display: none.

## Summary 
I started with media queries to change the text sizes and box layout for different screens. Then I added Bootstrap columns and a collapsible navbar. Finally, I combined both methods in a portfolio section with project cards and my personal information. This helped me understand how to use my own CSS together with Bootstrap.
